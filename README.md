# Minecraft Bedrock API script em Addons

* [API usada](https://github.com/Mojang/bedrock-samples)
* [Documentação de criação de addons no minecraft bedrock](https://learn.microsoft.com/pt-br/minecraft/creator/?view=minecraft-bedrock-stable)

---

Eu criei 2 addons que usam somente javascript usei a versão `"2.10.0"` do `"@minecraft/server"`. No primeiro addon coloquei só contador de tempo a cada 5 segundos. Já no segundo addon, implementei comandos para dar boas vindas ao jogador e alterar o piso de todos os jogadores.

# Como usar no jogo?

Para colocar no jogo precisa que você baixe um dos arquivo Scripts-BP presente nos addons e compacta o arquivo, após isso, renomeie a extensão do arquivo para `.mcaddon` ou `.mcpack`. Abra o arquivo e abre no minecraft bedrock. No jogo, crie um novo mundo, e ative no Pacotes de Comportamentos o chamado `Scripts no minecraft bedrock` e ative os comandos em Jogo.
